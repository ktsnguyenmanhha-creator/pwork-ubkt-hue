Hướng dẫn Cài đặt & Sử dụng trên Điện thoại, Laptop và Máy tính bàn

          
Ứng dụng Web độc lập (Standalone Web App) — Không cần cài đặt phức tạp, hoạt động mượt mà trên mọi thiết bị

        

        
      


      

        
        

          

            

              
📱 Sử dụng & Cài đặt trực tiếp trên iPhone

              
Bạn có thể bật ngay giao diện tối ưu riêng cho iPhone tại đây hoặc lưu/chia sẻ thành ứng dụng ngoài màn hình chính (kèm sẵn dữ liệu hiện tại):

            

            
          


          

            
            
            
          


          

        


        
        

          

            
Bước 1: Tải file ứng dụng độc lập (.html) về máy

            
Toàn bộ phần mềm được đóng gói trong 1 file duy nhất. Bạn chỉ cần tải về là có thể mở trực tiếp trên trình duyệt Chrome, Edge, Safari, Cốc Cốc bất cứ lúc nào.

          

          
        


        
        

          
          

            

              💻🖥️
              1. Trên Laptop & Máy tính bàn
            

            
    
              
  • Lưu file pWork_UBKT_Hue.html vào thư mục công việc trên máy.
    • 
              
  • Nhấp đúp để mở bằng Google Chrome, Microsoft Edge hoặc Safari.
    • 
              
  • Nhấn Ctrl + D (hoặc Cmd + D) để đánh dấu lên thanh Bookmark mở 1 chạm mỗi sáng.
    • 
              
  • Trên Edge/Chrome: Chọn Menu (⋮) → Lưu và chia sẻ → Tạo lối tắt (Create Shortcut) và tích chọn "Mở dưới dạng cửa sổ" để ghim biểu tượng ra ngoài màn hình Desktop/Taskbar như phần mềm độc lập.
    • 
            

          


          
          

            

              📱
              2. Trên iPhone / iPad (iOS)
            

            
    
              
  • Cách nhanh nhất: Gửi file .html qua Zalo / iCloud Drive về iPhone, hoặc đưa file lên đường link cá nhân miễn phí (như app.netlify.com/drop hoặc GitHub Pages).
    • 
              
  • Mở bằng trình duyệt Safari trên iPhone.
    • 
              
  • Nhấn nút Chia sẻ (Share) ở thanh dưới cùng → chọn Thêm vào Màn hình chính (Add to Home Screen).
    • 
              
  • Biểu tượng MH (pWork UBKT Huế) sẽ xuất hiện ngay trên màn hình chính iPhone và mở toàn màn hình chuẩn Liquid Glass iOS 27.
    • 
            

          


          
          

            

              🔄
              3. Trên Android & Đồng bộ dữ liệu
            

            
    
              
  • Trên điện thoại Android: Mở trang bằng Chrome → nhấn Menu (⋮) góc trên phải → chọn Thêm vào Màn hình chính.
    • 
              
  • Đồng bộ giữa Máy tính & Điện thoại: Vào mục Chế độ dữ liệu & Sao lưu → nhấn Tải file Sao lưu (.json) trên máy tính, gửi qua Zalo/Drive và nhấn Khôi phục từ file (.json) trên điện thoại.
    • 
              
  • Hoặc dùng nút Xuất Excel / Nhập từ Excel ngay trên Bảng công việc để báo cáo tổng hợp.
    • 
            

          

        


        
        

          
Mẹo thao tác nhanh hằng ngày cho Kiểm tra viên & Lãnh đạo phòng:

          

            
• Phím tắt bàn phím: Nhấn N để tạo việc mới, B để thu gọn menu trái trên Laptop, 1 2 3 để chuyển nhanh 3 phân hệ.

            
• Chuyển trạng thái 1 chạm: Rê chuột lên thẻ công việc (hoặc chạm trên điện thoại) rồi bấm nút Bắt đầu →, Trình duyệt → hoặc ✓ Duyệt xong.
